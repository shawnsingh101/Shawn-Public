# New York Funding Finder and Gillibrand Record Search (public site)

This repository only hosts the published website files. It is updated
automatically every day; changes made here directly will be overwritten.

- Gillibrand Record Search: bills from Congress.gov and press releases from gillibrand.senate.gov
- New York Funding Finder (`grants/site/`): federal programs (SAM.gov), funding notices (Grants.gov),
  New York State grant opportunities (Statewide Financial System), and entries reviewed or added by the office

Prototype for internal review. Not an official publication.
